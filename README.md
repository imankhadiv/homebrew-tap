# homebrew-tap

Homebrew casks for [f9s](https://github.com/imankhadiv/f9s), a k9s-style
terminal UI for Apache Flink®.

```sh
brew install imankhadiv/tap/f9s
```

Casks are published automatically by GoReleaser on each f9s release.
